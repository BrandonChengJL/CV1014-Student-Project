## Anime Recommendation System

# Overview

This project was developed as part of the CV1014 Mini Project group assignment.

The application is a desktop-based Anime Recommendation System built using Python, Tkinter, NumPy, and Pandas. It provides users with anime recommendations through an interactive graphical user interface (GUI), allowing users to search and explore anime titles efficiently.

# Features
User-friendly GUI built with Tkinter
Anime search functionality
Anime recommendation generation
Data processing and filtering using Pandas
Numerical computations using NumPy
Interactive desktop application

# Technologies Used
Python
Tkinter – GUI development
Pandas – Data manipulation and analysis
NumPy – Numerical computations
